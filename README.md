# منتجات رقمية — Digital Products

موقع الشركة لعرض البرامج وتجربتها وطلب معلوماتها عبر واتساب.

- الرئيسية: بطاقات البرامج، بحث وتصنيف، طريقة الطلب، وتعريف الشركة وأسئلة شائعة.
- صفحة مستقلة لبرنامج الأنشطة الصفية: `programs/class-activities.html`.
- أزرار التجربة تربط بالنسخة التجريبية المنشورة، ولا تعدّل برنامج الأنشطة نفسه.
- الطلب يفتح رسالة واتساب؛ لا إرسال تلقائي، ولا دفع إلكتروني، ولا تخزين لبيانات الطلب على خادم.

## تعديل الرقم

غيّر `whatsappNumber` في `assets/site-config.js`، مع مفتاح الدولة وبدون `+` أو مسافات. الرقم التجريبي الحالي: `96895214998`.

غيّر `demoUrl` في الملف نفسه لتحديث رابط تجربة برنامج الأنشطة.

## التشغيل

الموقع HTML/CSS/JavaScript ثابت، دون خطوة بناء. في مستودع GitHub ملفات الموقع موجودة بالجذر. في نسخة نشر Sites توجد داخل `dist/`.

للتجربة محليًا شغّل خادم ملفات ثابتًا، مثل `python -m http.server 8000` من مجلد الموقع، ثم افتح `http://localhost:8000`.

## إضافة برنامج

أضف بطاقة ببياناتها إلى الرئيسية وصفحة HTML داخل `programs/`، واضبط `data-order` باسم البرنامج لتجهيز رسالة طلب باسمه تلقائيًا. لا تعرض برنامجًا على أنه متاح قبل جاهزيته.
