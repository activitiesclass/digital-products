# منتجات رقمية — Digital Products

موقع عربي متجاوب للشركة بهوية داكنة، يعرض البرامج وصفحات تفاصيلها وطلبها عبر واتساب.

- الرئيسية: بطاقة برنامج الأنشطة الصفية، طريقة الطلب، متطلبات تجهيز المدرسة، والأسئلة الشائعة.
- صفحة البرنامج: `programs/class-activities.html`؛ 19 نشاطًا وأداة، قوالب أسئلة، ووضع الورش.
- عند الطلب تحصل المدرسة على رابط خاص بها، ويستلزم التجهيز قائمة الطلاب مع الصفوف والشعب، شعار المدرسة، وجدول توقيت الحصص.
- روابط تجربة البرنامج تستخدم بيانات وهمية؛ الموقع التسويقي لا يعدّل البرنامج نفسه.

## التواصل

عدّل `whatsappNumber` في `assets/site-config.js` بمفتاح الدولة ومن دون + أو مسافات. الرقم المؤقت الحالي `96895214998` مستنتج من رسالة المستخدم ويحتاج تأكيدًا قبل استقبال الطلبات الفعلية.

لأزرار الطلب روابط HTML مباشرة تعمل قبل تحميل JavaScript. يفتح الطلب في الصفحة نفسها عبر `wa.me`، ويوجد رابط بديل عبر `api.whatsapp.com` وخيار نسخ الرقم. النموذج يجهز اسم المدرسة والاستفسار داخل الرسالة ولا يرسل تلقائيًا. عند تغيير الرقم، حدّث الروابط المباشرة ورقم النموذج أيضًا للحفاظ على عملها دون JavaScript.

## التشغيل

HTML/CSS/JavaScript ثابت بلا بناء. ملفات GitHub في الجذر؛ نسخة Sites داخل `dist/`. لإضافة برنامج، أنشئ بطاقته وصفحة مستقلة له وتأكد من أن روابط الطلب والتجربة تعمل من HTML مباشرة.
